# CrazyTimeStrategy.top

Next.js build for the CrazyTimeStrategy.top launch plan.

## Stack

- Next.js 16 App Router
- React 19
- TypeScript
- Tailwind CSS v4

## Included in this build

- Homepage with hero, guide cards, featured Stake section, latest articles, and tool previews
- Seeded money pages, RTP/math pages, bonus feature pages, and branded Stake pages
- Blog index plus six seeded cluster posts
- Five interactive tools:
  - `bankroll-calculator`
  - `bet-size-calculator`
  - `session-planner`
  - `risk-level-calculator`
  - `rtp-calculator`
- SEO basics:
  - metadata
  - sitemap
  - robots
  - internal linking blocks
  - affiliate disclosure and responsible gambling footer copy

## Commands

```bash
npm install
npm run dev
npm run lint
npm run typecheck
npm run build
```
